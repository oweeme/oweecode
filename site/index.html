CaracterísticasFeatures

Todo lo que necesitasEverything you need

Sin plugins extra y sin gigabytes de RAM.No extra plugins, no gigabytes of RAM.

✏️

Editor y terminal

Editor & terminal

Resaltado para decenas de lenguajes, autocompletado con LSP, búsqueda en el proyecto, Git y terminal integrados.

Highlighting for dozens of languages, LSP completion, project search, built-in Git and terminal.

💬

Chat de equipo

Team chat

Las salas de Oweeme en la barra lateral, con código, capturas, flujos, vista previa y tareas del proyecto.

Oweeme rooms in the sidebar, with code, screenshots, flows, preview and project tasks.

🌐

Navegador con proyectos

Project-aware browser

Detecta tus servidores (80, 3000, 9000…), arranca el de tu proyecto, vista dividida, recarga en vivo y favoritos.

Finds your servers (80, 3000, 9000…), starts your project's, split view, live reload and bookmarks.

🔀

Flujos de negocio

Business flows

Diseña procesos con bloques, ejecútalos con scripts en cualquier lenguaje, siembra datos y genera código base.

Design processes with blocks, run them with scripts in any language, seed data and generate starter code.

📡

FTP / SFTP / FTPS

Como FileZilla: teclado, cola de transferencias, sincronización de carpetas y verificación de claves y certificados.

FileZilla-style: keyboard, transfer queue, folder sync and key/certificate verification.

🗄️

Bases de datos y API

Databases & API

MySQL, PostgreSQL, SQLite y Redis, diagrama ER, cliente de API con colecciones y generador de clientes.

MySQL, PostgreSQL, SQLite and Redis, ER diagram, API client with collections and client generator.

🎨

Diseño visual

Visual design

Edita Quasar, Vue y HTML visualmente, y diseña interfaces nativas para Qt, QML, GTK y juegos.

Edit Quasar, Vue and HTML visually, and design native UIs for Qt, QML, GTK and games.

🤖

IA local y en la nube

Local & cloud AI

Asistente con tus proveedores, agente local con Ollama y CLIs como Claude Code, Gemini y Aider.

Assistant with your providers, a local agent with Ollama and CLIs like Claude Code, Gemini and Aider.

Podman and Docker with pods, logs and shell; diagnostics for Capacitor, Android, Flutter, Qt, GTK and Godot.
